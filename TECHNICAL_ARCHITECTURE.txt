================================================================================
DECISION LOGIC FLOW
================================================================================

THRESHOLD EVALUATION:
━━━━━━━━━━━━━━━━━━━

Input: customer, proposed_discount, calculated_margin, amount

Step 1: Get customer tier
        tier = customer.tier

Step 2: Get tier max_auto_approval_discount
        tier_max = tier.max_auto_approval_discount  (e.g., 10%)

Step 3: Check primary threshold
        if proposed_discount > tier_max
            → is_approval_required = TRUE

Step 4: Check secondary thresholds (from ApprovalRule)
        Query ApprovalRule WHERE
            is_active = TRUE
            AND min_discount <= proposed_discount
            AND max_discount >= proposed_discount
            AND min_amount <= amount

Step 5: For each matching rule
        if rule.min_margin is not NULL
            AND calculated_margin < rule.min_margin
                → is_approval_required = TRUE
                → required_role = rule.required_role

Step 6: Check hard limit (margin < 20%)
        if calculated_margin < 20%
            → is_approval_required = TRUE

Step 7: Return decision
        {
          is_approval_required: bool,
          required_role: "sales-manager" or "finance",
          reason: "Discount exceeds tier limit"
        }

Output: Approval decision with required role


UPSELL RE-EVALUATION:
━━━━━━━━━━━━━━━━━━━

Input: quote (status="Approved"), new_upsell_product

Step 1: Add product to quote_items

Step 2: Recalculate all quote totals
        new_subtotal, new_amount, new_margin

Step 3: Run evaluate_approval_rules() with new numbers

Step 4: Compare result
        if new evaluation says is_approval_required = TRUE
            AND quote.status was "Approved"
                → Set quote.status = "Pending Approval"
                → Reset approval (decided_by_user_id = NULL)
        else
            → Keep quote.status = "Approved"

Output: Quote reverted to approval queue (if needed)

================================================================================
ERROR HANDLING
================================================================================

Errors Handled:
───────────────

1. Invalid discount (< 1% or ≥ 100%)
   → HTTPException 400: "Discount must be 1-99%"

2. Quote not found
   → HTTPException 404: "Quotation not found"

3. Customer access denied
   → HTTPException 403: "Access denied: not authorized"

4. Product not found
   → HTTPException 400: "Product not found"

5. Approval not found
   → HTTPException 404: "Approval request not found"

6. Quote status invalid
   → HTTPException 400: "Recommendations only available for approved quotes"

All errors logged with context for debugging
