1. CUSTOMER NEGOTIATION
   ✅ Customer can propose discount on "Sent" quotations
   ✅ Discount can be 1-99%
   ✅ Optional reason/comment for negotiation
   ✅ System records negotiation in NegotiationLog

2. SMART THRESHOLD EVALUATION
   ✅ Uses ApprovalRule table (database-driven, not hardcoded)
   ✅ Evaluates customer tier, discount %, margin %, amount
   ✅ Replaces hardcoded 20% threshold with full rule engine
   ✅ Margin calculation includes proposed discount impact

3. AUTOMATIC APPROVAL (WITHIN THRESHOLD)
   ✅ If discount ≤ tier limit AND margin ≥ 20%
   ✅ Quote status: "Under Negotiation" (no manager needed)
   ✅ Customer can proceed to accept or request more time

4. MANAGER APPROVAL (EXCEEDS THRESHOLD)
   ✅ If discount > tier limit OR margin < 20%
   ✅ Quote status: "Pending Approval"
   ✅ Manager sees in approval queue with all details
   ✅ Manager actions: APPROVE / REJECT / REQUEST REVISION

5. UPSELL RECOMMENDATIONS (POST-APPROVAL)
   ✅ After manager approves, upsell recommendations appear
   ✅ Based on UpsellRule engine (existing, reused)
   ✅ Shows margin impact of each recommendation
   ✅ Manager can ADD TO QUOTE or DISMISS

6. EDGE CASE: RE-APPROVAL ON UPSELL
   ✅ If adding upsell pushes quote past threshold
   ✅ Quote automatically reverts to "Pending Approval"
   ✅ Prevents silent approval of out-of-policy quotes
   ✅ Manager must re-review with new calculations

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

Q: Quote shows "Pending Approval" but discount seems small
A: Check ApprovalRule table - may have other triggers (margin < min_margin)

Q: Upsell recommendations not appearing
A: Verify UpsellRule records exist with active=true and matching trigger products

Q: Quote reverts to "Pending Approval" after adding upsell unexpectedly
A: This is correct behavior - margin dropped below 20% threshold, requires re-approval

Q: Manager can't approve - gets error
A: Verify manager has "sales-manager" role and approval exists with correct status

Q: Calculations not matching expected values
A: Verify products have correct price/cost in database, check decimal precision
