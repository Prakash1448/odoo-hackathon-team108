╔════════════════════════════════════════════════════════════════════════════╗
║                         API CALL SEQUENCE                                 ║
╚════════════════════════════════════════════════════════════════════════════╝

1. Customer proposes discount:
   POST /api/portal/quotes/quote-123/negotiate
   {proposedDiscount: 15, comment: "..."}
   → Creates NegotiationLog (sender_type: "Customer")

2. Sales Rep fetches quote:
   GET /api/quotes/quote-123
   → Returns quote with negotiationLog array

3. Sales Rep responds:
   POST /api/portal/quotes/quote-123/negotiate/respond
   {comment: "We can offer 12%", proposedDiscount: 12}
   → Creates NegotiationLog (sender_type: "Sales")

4. Customer fetches quote:
   GET /api/portal/quotes/quote-123
   → Returns quote with ALL negotiationLog entries
   → Frontend displays complete timeline
