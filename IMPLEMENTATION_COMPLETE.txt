                              FEATURES
================================================================================

SALESPERSON DASHBOARD:
  - Total Requests (all customer requests)
  - Pending Requests (Submitted or Under Review status)
  - Quotations Created (total quotations created by salesperson)
  - Quotations Sent (quotations sent to customers)
  - Quotations Awaiting Action (awaiting customer response)
  - Active Discount Requests (pending or requires manager approval)

REQUEST MANAGEMENT:
  - View all customer requests with details
  - See customer company and contact info
  - Update request status through workflow
  - View associated quotation (if exists)
  - Create quotation directly from request

QUOTATION WORKFLOW:
  - Create quotations with line items
  - Add multiple products/services per quotation
  - Automatic calculations:
    * Subtotal = sum of (quantity × unit_price)
    * Discount = percentage-based on subtotal
    * Tax = calculated on (subtotal - discount)
    * Total = subtotal - discount + tax
  - Set discount and tax percentages
  - Add notes and validity period
  - Send quotation to customer (Draft → Awaiting Customer Response)
  - Track quotation status

DISCOUNT REQUEST HANDLING:
  - View all customer discount requests
  - See customer's reason and message
  - Review current vs requested discount
  - Respond with:
    * Approval (apply discount)
    * Rejection (decline discount)
    * Counter Offer (suggest different)
    * Requires Manager Approval (escalate)
  - Add salesperson's response notes

DATA INTEGRATION:
  - Real-time data from MySQL database
  - Customer data isolation (customers see only their data)
  - Salesperson sees all customers' requests
  - Automatic status updates across modules
  - Full audit trail (timestamps on all records)

                          TECHNICAL DETAILS
================================================================================

ARCHITECTURE:
  - Separate authentication tokens for customer and salesperson
  - Role-based middleware enforcement
  - MySQL database with connection pooling
  - RESTful API design
  - React frontend with client-side routing
  - Vite build tool (fast development)

AUTHENTICATION:
  - Customer: JWT token with customerId payload
  - Salesperson: JWT token with salespersonId payload
  - 7-day token expiry
  - Automatic logout on 401 (invalid/expired token)
  - bcryptjs password hashing (10 salt rounds)

SECURITY:
  - No hardcoded credentials
  - Environment variables for all secrets
  - Parameterized SQL queries (prevents injection)
  - CORS restricted to frontend domain
  - Server-side validation on all inputs
  - Data isolation at query level

DATABASE:
  - MySQL 8.0+
  - 7 tables (6 existing + 1 new)
  - DECIMAL(12,2) for monetary values
  - ISO 8601 timestamps
  - Foreign key relationships
  - Indexes on frequently queried columns

DEPLOYMENT:

  - npm dependencies management
  - Environment-based configuration
  - Production-ready error handling
  - Logging and monitoring points in place
